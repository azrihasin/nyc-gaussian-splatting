# Splat FPS + In-app Collider Editor

## Setup
```bash
npm install
npm run dev
```

## Notes
- Your splat is served from `public/room.splat`.
- Toggle **EDIT/PLAY** in the UI.
- In EDIT: click a translucent box to select, then Move/Rotate/Scale with the gizmo.
- Save/Load via LocalStorage, Export/Import JSON via the panel.
